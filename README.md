## 🛠️ Core Technical Knowledge Domains

### 1. Network Architectures & Foundations
* **Topologies & Models:** Designed physical and logical architectures (Star, Mesh, Bus) across both peer-to-peer and client-server frameworks. Mastered the 7-Layer OSI model and 4-Layer TCP/IP protocol suite, focusing heavily on packet encapsulation and de-encapsulation.
* **Physical Infrastructure:** Studied network mediums including Twisted-Pair Copper (TIA/EIA 568A & 568B wiring standards), Coaxial, and Fiber Optic cabling. Evaluated selection criteria such as plenum ratings and transmission types (Duplex vs. Half-Duplex).
* **Enterprise Hardware:** Deep conceptual understanding of Network Interface Cards (NICs), hubs, managed vs. unmanaged switches, routers, modems, all-in-one SOHO gateways, media converters, and VoIP endpoints.

### 2. The TCP/IP Protocol Stack
* **Network Layer:** Mastered the structural layout of Address Resolution Protocol (ARP), Internet Protocol (IP), and Internet Control Message Protocol (ICMP).
* **Transport Layer:** Analyzed connection-oriented vs. connectionless communication (TCP vs. UDP session state tracking), alongside ports and socket structures.
* **Application Layer:** Deep-dive into core network services including Management (DNS hierarchy, DHCP leasing, NTP time sync), Remote Access (SSH, RDP), File Transfer (FTP, SFTP), Mail protocols, and Web delivery (HTTP vs. HTTPS).

### 3. IP Engineering & Custom Subnetting
* **Binary Math:** Developed fluency in binary-to-decimal conversions to manually compute network address boundaries.
* **IPv4 Design:** Engineered class-based schemes (Class A, B, C), separated public vs. private RFC 1918 address ranges, and analyzed loopback routing.
* **Subnetting Mechanics:** Divided flat Class C networks into multiple, efficient subnets to maximize IP conservation and establish clear broadcast boundaries.
* **IPv6 Next-Gen:** Learned IPv6 hex structures, transmission types (Unicast, Multicast, Anycast), compatibility translation, and the Neighbor Discovery Protocol (NDP).

### 4. Advanced Routing, Switching, & Security
* **Switching Logic:** Analyzed how switches build MAC address tables, mitigate collision domains, manage broadcast domains, and handle CSMA/CD. Studied Layer 3 multi-layer switching, Port Mirroring, and Power over Ethernet (PoE).
* **Routing Logic:** Configured static, dynamic, and default routes. Studied Administrative Distance (AD), metrics, Interior Gateway Protocols (IGPs like RIP), and Exterior Gateway Protocols (EGPs like BGP).
* **Network Hardening & WAN:** Implemented edge technologies like Network Address Translation (NAT), Port Forwarding, and Demilitarized Zones (DMZs). Covered WAN services (DSL, Cable, Leased Lines, Metro Ethernet, Satellite), Software-Defined Networking (SDN/SD-WAN), and fundamental security policies (CIA Triad, Least Privilege, Defense-in-Depth, Firewalls, VPNs, and IDS/IPS).

## 💻 Description of Completed Labs & Practical Exercises

The following hands-on environments were fully constructed, tested, and validated using Cisco Packet Tracer and native operating system command-line interfaces:

* **Lab 1 & 2: Network Virtualization Basics** – Deployed the Packet Tracer platform and successfully established a baseline physical link connecting two distinct host PCs over a copper medium.
* **Lab 3 & 4: Topology & SOHO LAN Deployment** – Built functional physical wired topologies and simulated a full Small Office/Home Office (SOHO) Local Area Network integrating a central gateway, local clients, and modern network endpoints.
* **Lab 5: Cabling Infrastructure Review** – Conducted hands-on physical medium assessments, mapping out precise selection rules and structural standard wiring configurations.
* **Command Line Diagnostics & Wireshark Captures** – Used terminal environments across Windows and Linux to run native network tools (Ping, Traceroute, and NSLookup). Captured traffic to analyze the exact packet structure of live ARP and ICMP sequences.
* **Lab 6 & 7: Static Addressing & Custom Subnetting** – Programmed independent static IP profiles across local hosts and broke a single network pool down to build two isolated LANs running on unique, functional subnets.
* **Lab 8 & 9: DHCP Automation & Core DNS Services** – Configured an automated Windows Server DHCP pooling architecture to lease dynamic client IPs alongside a dedicated local DNS and Web Server deployment.
* **Lab 10: Switch Segmentation via VLANs** – Implemented internal network segmentation by programming independent Departmental Virtual LANs (VLANs) on an enterprise switch to cleanly divide corporate broadcast domains.
* **Lab 11: Dynamic Routing Protocols** – Configured multi-router architectures to dynamically compile, updates, and balance network routing tables across the infrastructure using the Routing Information Protocol (RIP).
* **Lab 12: Wireless Infrastructure & IoT Integration** – Deployed a local Wireless Access Point (WAP) into a wired LAN, selecting optimized frequencies, channels, and security criteria to support mobile and IoT devices.
* **Lab 13: Edge Firewall Architecture** – Deployed host-based security rules on server appliances to systematically drop incoming ICMP traffic, effectively shielding the system from external network discovery scans.
